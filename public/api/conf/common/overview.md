[Apprenticeship Levy](https://www.gov.uk/guidance/pay-apprenticeship-levy) is applied to organisations with large payrolls (broadly speaking, payrolls in excess of £3 million). The purpose of this API is to allow the Digital Apprenticeship Service (DAS) to access information about the levy that an organisation has paid.
    
An employer makes levy declarations as part of an Employer Payment Summary (EPS) submission to the PAYE RTI system. These submissions are made in respect of a payroll scheme identified by an employer reference (*empref*) and form the primary source of data for this API. See the [HMRC page about EPS](https://www.gov.uk/guidance/what-payroll-information-to-report-to-hmrc#eps-what-to-report) for details about what data appears on an EPS submission. For even more detail, including the specific XML schema and business rules that are applied to EPS submission, see the [RTI information pages for software developers](https://www.gov.uk/government/collections/real-time-information-online-internet-submissions-support-for-software-developers). The technical specifications sections for each tax year contain links to a `.zip` file that includes the XML Schema file and Schematron rules for the tax year.
    
Most submissions will include a year-to-date (YTD) figure for the total levy declared in the current tax year. However, there may be times that no levy or values for other fields are relevant, in which case the employer might file an EPS with an indication of a Period of Inactivity or No Payment for Period. The API is able to reflect these situations.
